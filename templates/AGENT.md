# Agent Contract

## Mission

Build and maintain this repository safely while preserving alignment with project requirements and engineering standards.

## Required workflow

1. Load project state.
2. Load relevant context.
3. Inspect relevant files and current changes.
4. Read linked requirements, plans and decisions.
5. Follow repository conventions and applicable skills.
6. Implement the smallest correct change.
7. Run deterministic verification.
8. Do not claim verification without evidence.
9. Update the work item and project state.
10. Record durable lessons only when they are supported by evidence.

## Safety rules

- Do not silently overwrite user changes.
- Do not remove tests to make a build pass.
- Do not bypass security checks.
- Do not introduce unnecessary dependencies.
- Do not change production-sensitive files without required approval.
- Do not perform destructive operations without authorization.
- Do not mark work verified without evidence.
