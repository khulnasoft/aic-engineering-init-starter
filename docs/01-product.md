# AIC Product Vision

## Positioning

AIC is an AI-native engineering control plane for creating and evolving software projects.

It combines:

- Project bootstrapper
- Repository intelligence layer
- AI planning system
- Code scaffolding engine
- Work-item manager
- Agent execution runtime
- Evidence-driven verification engine
- Engineering memory
- Governance and policy system

It should not be treated as only an AI code generator or starter-template CLI.

## Core equation

```text
AIC =
Project State
+ AI Intelligence
+ Engineering Workflow
+ Deterministic Tools
+ Evidence
+ Verification
+ Memory
+ Governance
```

## Core promise

Maintain a trustworthy relationship between:

```text
what the team wants
→ what was planned
→ what the repository contains
→ what has actually been verified
```

## Product pillars

### 1. Discover
Understand an existing or new repository.

### 2. Define
Capture product goals, requirements, constraints and acceptance criteria.

### 3. Plan
Turn requirements into milestones, architecture, decisions, plans and work items.

### 4. Build
Scaffold, generate, migrate and refactor safely.

### 5. Execute
Allow an agent to work on individual tasks or run an autonomous loop.

### 6. Verify
Use tests, AST analysis, typechecking, linting, builds, security tools and runtime evidence.

### 7. Learn
Promote verified observations into durable project memory.

### 8. Govern
Control destructive actions, dependencies, credentials, production changes and policy exceptions.
